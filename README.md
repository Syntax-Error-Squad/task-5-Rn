# Python lab 5
____
## Условие задачи:
### Задание 5.
Реализовать функцию-фабрику `make_point_class(n, name=None)`, которая:
- Создаёт новый класс `PointN` с ровно `n` атрибутами-координатами: `x0`, `x1`, …, `x(n-1)`.
- Каждый атрибут управляется экземпляром дескриптора `CoordDescriptor`, который:
  - проверяет, что значение — число (`int` или `float`);
  - вызывает `TypeError` при неверном типе.
- Конструктор нового класса принимает ровно `n` позиционных аргументов (координат).
- Класс содержит метод `to_tuple()`, возвращающий координаты как кортеж.
- Классы кэшируются через `functools.lru_cache`, чтобы повторные вызовы для одного `n` не создавали класс заново.
____
## Описание решения
____
- `CoordDescriptor` — дескриптор одной координаты. Принимает только `int` и `float` (`bool` не допускается), иначе выбрасывает `TypeError`. Значение хранится в слоте с подчёркиванием (для `x0` — `_x0`).
- `make_point_class(n, name=None)` проверяет аргументы и вызывает закэшированную через `lru_cache` функцию `_make_point_class`. Проверка выполняется до обращения к кэшу, поэтому `make_point_class(3)`, `make_point_class(n=3)` и `make_point_class(3, None)` возвращают один и тот же класс.
- Если `n` не целое число (или `bool`) либо `name` не строка и не `None`, выбрасывается `TypeError`; если `n < 1` — `ValueError`.
- Имя класса по умолчанию — `f"Point{n}"`, его можно задать через `name`.
- Класс создаётся через `type(...)` и использует `__slots__`, поэтому лишние атрибуты добавить нельзя.
- Точки неизменяемы: координату можно задать только один раз — в конструкторе. Изменение или удаление атрибута вызывает `AttributeError`, а «изменённая» точка создаётся методом `replace()`.
- При неверном числе аргументов конструктора выбрасывается `TypeError`.

| Метод | Описание |
|---|---|
| `to_tuple()` | Координаты в виде кортежа `(x0, ..., x(n-1))` |
| `replace(**changes)` | Новая точка с заменёнными координатами, например `p.replace(x0=10)` |
| `__repr__` | Строка вида `Point3(x0=1, x1=2.5, x2=-3)` |
| `__eq__`, `__hash__` | Сравнение по координатам (только точки одного класса); точки можно хранить в `set` и использовать как ключи `dict` |

### Использование в своём коде
```python
from task_5_Rn import make_point_class

Point3 = make_point_class(3)
p = Point3(1, 2.5, -3)
print(p.to_tuple())              # (1, 2.5, -3)
print(p.x1)                      # 2.5
print(p.replace(x0=10))          # Point3(x0=10, x1=2.5, x2=-3)
print(make_point_class(3) is Point3)  # True — класс взят из кэша
```
